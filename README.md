# Lesson 37 — October Review · Silly Fill-in Stories 🎉

Playful-Detective teaching pack for a one-hour online English lesson (Grade 5): the **Silly Fill-in Story** game (choose the right type of word, drop it into a secret story, read the chaos aloud), then a **quick-fire October review** — conditionals, may/might/could, sentence types, verb agreement, comparatives, synonyms & antonyms, a/an, hyperbole & oxymoron.

**Open `index.html`**, or publish this folder with GitHub Pages.

| File | What it is |
| --- | --- |
| `index.html` | Home page linking the lesson and both games |
| `lesson-37-silly-fill-in-stories.html` | The 13-slide lesson with the game built in (arrow keys, thumbnail rail, ⛶ Present) |
| `lesson37-game.js` | The game logic (two stories, Word Collector, drum roll + confetti reveal) |
| `cat-connect-4.html` | Connect 4 against the cat |
| `cat-word-search.html` | Word search with the cat |

Upload everything (including `stickers/`, `cats/`, `fonts/`, `slides/` and `.nojekyll`). Keep file names exactly as they are.
